# Did an AI pilot actually save money? A checklist

A before-and-after audit for any AI tool a practice has piloted or bought, scribe or otherwise. The reasoning and a worked example from our own business are in [How Do You Tell Whether an AI Pilot Actually Saved Money?](https://seriousai.partners/how-do-you-tell-whether-an-ai-pilot-saved-money/)

## 1. Find the before number

- [ ] What did this work cost before the tool, in staff hours, outside fees or both?
- [ ] Is that figure written down from the time before go-live? If not, rebuild it first from schedules, payroll or invoices for the same months, and note that it's a rebuild.

## 2. Count everything the new version costs

- [ ] The subscription or license.
- [ ] The model or usage bill, if it's separate.
- [ ] The hours people still put into checking and correcting the tool's output.
- [ ] Anything that was supposed to be cancelled and wasn't.

## 3. Measure the same way on both sides

- [ ] Same unit (per visit, per claim, per month).
- [ ] Same months of the year, so seasonality doesn't do the work.
- [ ] Same source report before and after.

## 4. Check the output didn't get worse

- [ ] Run the old way and the new way on the same inputs and compare the answers.
- [ ] Was an accuracy bar written down before go-live? If so, does the tool meet it?

## 5. Watch for work that moved instead of disappearing

- [ ] Did the saved hours go somewhere you can name (more visits, a vacancy not backfilled, overtime cut)?
- [ ] Or did the same work shift to another person or another step?

## 6. Decide

- [ ] Cost after, all in, is below cost before, measured the same way, and quality held: keep it.
- [ ] Costs are higher or the output got worse: renegotiate, fix the workflow, or cancel.
- [ ] No before number and no way to rebuild one: start measuring now, and decide at the next renewal.

A measuring aid, not legal, billing or compliance advice.
